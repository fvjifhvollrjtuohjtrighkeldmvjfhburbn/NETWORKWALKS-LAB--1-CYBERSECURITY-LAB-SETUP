# NETWORKWALKS-LAB--1-CYBERSECURITY-LAB-SETUP
 Cybersecurity Lab Setup
Building a virtual lab for cybersecurity and ethical hacking practice.

Project Overview
I set up a virtual cybersecurity lab using VirtualBox and Kali Linux to learn about networking, Linux, and ethical hacking in a controlled environment.

Tools Used
VirtualBox
Kali Linux
7-Zip

Objectives
Configure a Kali Linux virtual machine.
Understand virtual networking and IP addressing.
Test network connectivity.
Learn basic Linux networking commands.
Create snapshots for recovery.
Prepare for future penetration-testing practice.

 Network Configuration
Network Mode: [NAT Network]
IP Address: [10.0.0.2]
Gateway: [10.0.0.1]
DNS: [10.0.0.1]

Verification Commands
ip a
ip route
ping <gateway-ip>
nslookup example.com

What I Learned
Virtual machine setup and management.
NAT Network configuration.
IPv4 addressing and DNS.
Basic Linux troubleshooting.
VM snapshots and recovery.
